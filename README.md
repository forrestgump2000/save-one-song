# Save One Song

Pick a year from 1980 to 2026 and get six well-known songs from it. Listen to 30-second previews, cut five, and save the one you'd keep. Your saved songs stay in your browser.

- Plain HTML, CSS and JavaScript in `public/`, with no build step
- The song list is in `public/songs.js`
- Album art and audio previews come from the iTunes Search API

Run locally:

```bash
python3 -m http.server 5391 -d public
```
